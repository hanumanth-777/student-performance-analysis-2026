# Student Performance Analysis

## Project Overview

A Python-based data analysis project that analyses student academic performance using Pandas, NumPy and Matplotlib.

The project demonstrates data cleaning, statistical analysis, student ranking and data visualization.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Features

- Load student records from CSV.
- Inspect dataset structure and statistics.
- Identify and handle missing values.
- Detect and remove duplicate records.
- Calculate subject-wise average marks.
- Calculate student percentages and rankings.
- Identify toppers.
- Perform pass/fail analysis.
- Analyse student attendance.
- Generate data visualizations.
- Export cleaned student records.

Install the required libraries:

```bash

```

## Run the Project

```bash
python analysis.py
```

## Dataset Information

The project uses a sample student dataset containing academic marks, attendance and student details.

The dataset includes missing values and duplicate records for data-cleaning practice.
